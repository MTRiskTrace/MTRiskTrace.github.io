# MTRiskTrace

Project page for **When and Why Do Agents Become Unsafe? A Trajectory-Aware Benchmark for Multi-Turn Agent Safety Evaluation**.

**Website:** [mtrisktrace.github.io](https://mtrisktrace.github.io/)

The page introduces the benchmark, its construction and safety-diagnosis framework, evaluation results, and a multi-turn case study. Table 2 is presented as an interactive leaderboard that can rank all harnesses or OpenClaw runs by overall attack success rate or an individual attack strategy.

## Local preview

This is a static site with no build step. Open `index.html` directly, or run a local server from this directory:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.
